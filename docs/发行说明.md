# SubFix v3.3.0 Windows 版 · 发行说明

发布日期：2026-09-28　|　基于上游 HooperH/SubFix macOS v3.3.0　|　分支：akahoz94/SubFix `windows-port`

## 四个包分别是什么

| 文件 | 大小 | 里面有什么 | 适合谁 |
|---|---|---|---|
| `SubFix-v3.3.0-Windows.zip` | 0.5 MB | 只有插件本体（Lua + Python 脚本 + 安装脚本） | 机器上已装 Python 3.10-3.13 和 ffmpeg 的用户 |
| `SubFix-v3.3.0-Windows-Full.zip` | 100 MB | 插件本体 + 内置便携 Python 3.11.9 + 内置 ffmpeg（含 DLL） | 不想装任何依赖，解压即用 |
| `SubFix-v3.3.0-Windows-Full-Max.zip` | 1.5 GB | Full 的全部内容 + 自编译 qwen3-asr-cli 加速对齐 + 对齐模型 GGUF（1.84 GB） | 想完全离线使用、要最快字幕对齐的用户 |
| `SubFix-v3.3.0-Windows-Setup.exe` | 2.4 MB | Inno Setup 中文安装向导（内容等同轻量包） | 习惯双击安装/要能从系统卸载的用户；支持静默部署 `Setup.exe /VERYSILENT` |

## 怎么选（一句话）

- 电脑里已经有 Python 和 ffmpeg → **轻量 zip**
- 什么都不想装 → **Full**
- 没网/不想联网下模型，还要最快的字幕对齐 → **Max**
- 想要正常安装向导、能卸载、公司批量部署 → **Setup.exe**

四个包插件功能完全一致，区别只在于自带多少运行环境。

## 安装方法

### zip 包（三个 zip 相同步骤）

1. **完整解压** ZIP（不要只拖单个文件出来）。
2. 双击 `安装_SubFix.bat` → 文件被复制到达芬奇脚本目录
   `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility`。
3. 重新打开 DaVinci Resolve，菜单 Workspace - Scripts - Utility 下找 SubFix。

### Setup.exe

双击按向导下一步即可（或管理员静默部署：`SubFix-v3.3.0-Windows-Setup.exe /VERYSILENT`）。
安装后同样在 Workspace - Scripts - Utility 里找 SubFix；可用系统"应用与功能"或
脚本目录下 `.subfix_uninstall\unins000.exe` 卸载。

## 首次使用本地识别（Qwen）

- **Max 包**：已内置对齐模型，识别模型首次生成字幕时自动从魔搭下载（约 1.7 GB，走国内源）。
- **其他包**：首次使用前双击安装后目录里的
  `%APPDATA%\...\Scripts\Utility\.subfix_support\setup_asr_env.cmd` 安装识别依赖（清华镜像）。
- **本机已有模型（免下载）**：生成字幕时插件会自动探测本机模型（环境变量、
  `%APPDATA%\SubFix\models` junction、默认库 `G:\AImodel`），发现后弹窗三选一——
  「使用本机模型」（登记后不再弹窗、绝不重复下载）/「重新下载（联网）」/关闭。
  也可提前双击 `接入本地模型.bat` 写入环境变量（默认指向 `G:\AImodel`，重启达芬奇生效）。
- **模型误删/想强制重下**：探测失败时自动回退联网下载；模型完好但想重下，在弹窗里选
  「重新下载（联网）」再点「Qwen（本地）」即可，重下完成自动清除强制标记。

## 卸载

- zip 用户：双击 zip 内 `卸载_SubFix.bat`，输入 UNINSTALL 确认。
- Setup 用户：系统"应用与功能"里卸载。
- 两者都保留：达芬奇项目、桌面 `HooperAI_Backups` 字幕备份、`%APPDATA%\SubFix` 下的识别模型。

## 已知边界

- bat 内中文提示按 GBK 编码（中文 Windows 默认代码页 936 正常显示）。若系统开了
  "Beta: 使用 Unicode UTF-8 提供全球语言支持"（代码页 65001），中文提示会乱码，
  但安装/卸载功能不受影响。
- 在线更新已停用（上游更新器只会下载 macOS 资产）；更新请到
  https://github.com/akahoz94/SubFix/releases 重新下载。
- 字幕轨 UI 自动切换功能在 macOS 上游即未接线（死代码），Windows 无功能损失。
